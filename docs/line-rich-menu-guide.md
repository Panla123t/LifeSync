# LifeSync: คู่มือการติดตั้ง LINE Rich Menu & รูปโปรไฟล์บอทซันนี่ (Sunny)

คู่มือนี้สรุปขั้นตอนการตั้งค่ารูปโปรไฟล์บอท (PFP) และเมนูลัดท้ายแชท (Rich Menu 6 ช่อง) บน **LINE Official Account Manager** สำหรับบอท **ซันนี่ (Sunny ID: `@766iowmg`)**

---

## 1. วิธีตั้งรูปโปรไฟล์บอทซันนี่ (Profile Picture)

1. **ดาวน์โหลดรูปโปรไฟล์ความละเอียดสูง**:
   - ไฟล์ภาพ: `public/mascot/sunny-avatar.jpg`
   - หรือดาวน์โหลดจากหน้า **Settings (ตั้งค่า)** ในเว็บแอป LifeSync
2. เข้าสู่ [LINE Official Account Manager](https://manager.line.biz/)
3. เลือกบัญชีของท่าน (`@766iowmg`)
4. ไปที่ **Settings (การตั้งค่า)** (มุมขวาบน) > **Account settings (การตั้งค่าบัญชี)**
5. ในช่อง **Profile photo (รูปโปรไฟล์)** คลิก **Change (เปลี่ยน)**
6. อัปโหลดรูปภาพ `sunny-avatar.jpg` แล้วกด **Save (บันทึก)**

---

## 2. วิธีติดตั้ง LINE Rich Menu 6 ช่อง (2500 x 1686 px)

### ขั้นตอนที่ 1: เตรียมรูปภาพ Rich Menu
ไฟล์ภาพความละเอียดสูง 2500x1686 พิกเซลพร้อมใช้งานอยู่ที่:
- `public/line/rich-menu-6tiles.png` (สร้างตามขนาดมาตรฐานของ LINE)

### ขั้นตอนที่ 2: สร้าง Rich Menu ใน LINE Official Account Manager
1. ในเมนูด้านซ้าย เลือก **Rich menus (ริชเมนู)**
2. คลิกปุ่ม **Create new (สร้างใหม่)**
3. **Title (ชื่อริชเมนู)**: ใส่ `LifeSync Main Menu`
4. **Chat bar text (ข้อความบนแถบเมนู)**: ใส่ `เมนูหลัก LifeSync` หรือ `แตะเพื่อเปิดเมนู`
5. **Menu display (การแสดงเมนู)**: เลือก `Display (แสดง)`

### ขั้นตอนที่ 3: เลือกเทมเพลตและอัปโหลดภาพ
1. คลิก **Select template (เลือกเทมเพลต)**
2. เลือก **Large (ขนาดใหญ่)** แบบ **6 ช่อง** (3 คอลัมน์ x 2 แถว)
3. คลิก **Upload background image (อัปโหลดรูปพื้นหลัง)** แล้วเลือกไฟล์:
   `public/line/rich-menu-6tiles.png`

### ขั้นตอนที่ 4: กำหนดคำสั่งการทำงาน (Actions) ทั้ง 6 ช่อง

| ช่อง | ชื่อเมนู | ประเภทการทำงาน (Action Type) | ค่าที่กรอก (Value) |
|---|---|---|---|
| **A** (แถวบน ซ้าย) | 💧 บันทึกดื่มน้ำ | **Text (ข้อความ)** | `ดื่มน้ำ` |
| **B** (แถวบน กลาง) | 📸 ถ่ายรูปอาหาร | **Text (ข้อความ)** | `วิเคราะห์อาหาร` |
| **C** (แถวบน ขวา) | 😴 บันทึกการนอน | **Text (ข้อความ)** | `บันทึกการนอน` |
| **D** (แถวล่าง ซ้าย) | 🎯 ภารกิจ & เลเวล | **Link (ลิงก์/URI)** | `https://liff.line.me/{YOUR_LIFF_ID}/quests` |
| **E** (แถวล่าง กลาง) | 📊 สรุปสุขภาพ | **Link (ลิงก์/URI)** | `https://liff.line.me/{YOUR_LIFF_ID}/dashboard` |
| **F** (แถวล่าง ขวา) | ⚙️ ตั้งค่า & บัญชี | **Link (ลิงก์/URI)** | `https://liff.line.me/{YOUR_LIFF_ID}/settings` |

> [!TIP]
> หากยังไม่ได้กำหนด LIFF ID สำหรับแต่ละหน้า สามารถใช้ Action Type เป็น **Text (ข้อความ)** เช่น `ภารกิจ`, `สรุปรายสัปดาห์`, `ตั้งค่า` หรือใส่ลิงก์เว็บไซต์ `https://lifesync.vercel.app/dashboard` แทนได้ทันที

4. คลิก **Save (บันทึก)** เมนูจะเริ่มแสดงบนหน้าแชทของบอทซันนี่ทันที!
